# Security Policy

## Supported Versions

As synapse-ai doesn't provide an official release yet, please use the latest version to receive security updates.
Currently, we have two branches to maintain:
* main branch for synapse-ai 2.x
* main-1.x branch for synapse-ai 1.x

## Reporting a Vulnerability

Please go to https://github.com/bytedance/synapse-ai/security to report the vulnerability you find.
